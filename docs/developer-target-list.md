# Developer Outreach Target List

## Sources to target
- Newly launched Android apps in Google Play
- r/androiddev
- r/gamedev
- #AndroidDev on X/Twitter
- #IndieGameDev
- Product Hunt Android launches from the last 90 days
- Indie game dev Discords and Slack groups

## Outreach notes
- Personalize the first sentence with the app name or launch note
- Keep it short and focused on the closed testing requirement
- Offer the direct solution, not a generic intro
- Send follow-ups within 48 hours if no response

## Track these fields
- Name
- App / company
- Source
- Email / contact link
- Reach date
- Response status
- Follow-up date

## Sample list format
- App Name | Contact | Source | Status | Notes
- Example: GameDev Studio | founder@company.com | X/Twitter | Not reached | launched 2 weeks ago
